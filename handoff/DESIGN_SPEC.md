# 设计说明 · 棱镜小电视（方案二）

> 目标软件：Siemens NX 2412（通过 CAD-Agent-Hub/MCP/UG 的 MCP 工具）
> 单位：**mm**（`create_part` 必须传 `units:"millimeters"`）
> 版本：2026-10 · v3 简约楔形版

---

## 1. 这是什么

一台放桌面上的"悬浮小电视"：

- 底部是一块水平主板（ESP32-PICO-D4 / 电源 / USB-C / 传感器）
- 上面是一个**后仰 30°** 的光学头：1.3" 240×240 IPS 屏 + 25.4mm 分光棱镜
- 屏幕朝上发光，经棱镜内 45° 分光面反射后，以 **30° 仰角**射向坐在桌前的人眼
- 外壳是暖米白哑光楔形，棱镜**直接粘接、四周完全裸露**

整机 **33 × 40 × 41.7 mm**。

---

## 2. 坐标系（先定死，后面全按这个）

右手系，**Z 向上，−Y 为"正面"（人眼方向），原点在底座底面中心（桌面高度）**。

```
        +Z
         │      ╱ 棱镜（后仰 30°）
         │    ╱
         │  ╱
   ──────┼──────► +Y（后）
        ╱│
       ╱ │  底座
      −Y │
```

| 基准 | 说明 |
|---|---|
| Z = 0 | 桌面 |
| Y = −20 | 外壳正面 |
| Y = +20 | 外壳背面 |
| X = ±16.5 | 外壳左右 |
| 光学头局部原点 | 屏幕板**底面中心**；局部 +Z = 屏幕法线 |

---

## 3. 光学原理（改参数前必读）

分光棱镜的 45° 分光面**做死在立方体里**，屏幕又必须紧贴并平行于棱镜底面。
所以唯一的自由度是"屏幕 + 棱镜一起后仰"：

```
入射 d = (0, 0, 1)            屏幕朝上发光
分光面法线 n = (0, 1, 1)/√2
出射 r = d − 2(d·n)n = (0, −1, 0)          射向"正面"

整体绕 X 后仰 TILT 后：
r_world = (0, −cos TILT, +sin TILT)        抬高 TILT 度
```

**TILT 就是人眼观察仰角**，不是造型参数：

- 30° ≈ 坐姿看桌面设备；45° ≈ 低头看手机
- 改大 → 更"正对眼睛"，但整机更高（25.4 棱镜竖直投影 ≈ 25.4·(cos+sin)）
- 改小 → 更矮，但画面被竖向压扁（30° 压 13%，15° 压 26%）

**⚠️ 前唇高度上限**：人眼在 TILT 仰角看时，托台前唇每高出棱镜底面 1mm，
就会挡掉约 `1/tan(TILT)` mm 画面。有效显示区只有 1mm 边距 →
**30° 时前唇最多只能高出棱镜底面 1.0mm**。本设计取 **0（齐平）**。
想要参考图那种 3–4mm 厚包边，必须把 TILT 降到 15° 左右。

## 4. 局部 → 世界变换（光学头）

光学头里的零件都按**局部坐标**建，最后整体变换到世界：

```
R = Rot(X, −TILT)                     绕 X 轴 −30°
T = (0, HEAD_Y0, HEAD_Z0)

HEAD_Z0 = 3.6 + YH·sin(TILT) = 10.60
HEAD_Y0 = −18 + YH·cos(TILT) = −5.876
```

即世界点 `p_world = R · p_local + T`。

派生量：

```
HL_Z   = PCB_T + PANEL_T + SHIELD_T + GLUE_T = 2.40     棱镜底面（局部）
HEAD_T = HL_Z + PRISM                        = 27.80    光学头沿轴总厚
TOTAL_H= HEAD_Z0 + YH·sin(TILT) + HEAD_T·cos(TILT) = 41.68
```

## 6. 逐特征建模顺序

### 6.1 P01 外壳底座（世界坐标）

**(1) 侧剖面草图** — 平面 `YZ`，原点 `[0,0,0]`，5 段闭合折线：

| # | 起点 (Y,Z) | 终点 (Y,Z) |
|---|---|---|
| 1 | (−20, 0) | (20, 0) |
| 2 | (20, 0) | (20, 6) |
| 3 | (20, 6) | (2.09, 6) |
| 4 | (2.09, 6) | (−20, 18.7546) |
| 5 | (−20, 18.7546) | (−20, 0) |

**(2) 拉伸** — 沿 `X`，`start = −16.5`，`distance = 33` → x ∈ [−16.5, 16.5]

**(3) 挖内腔** — 方块 `29 × 31 × 38`，角点 `(−14.5, −13, 2)` → 布尔 **subtract**
> 前部 y < −13 保持实心（这段是托光学头的楔）

**(4) 正面盲槽** — 方块 `22 × 6 × 6`，角点 `(−11, −20.5, 7)` → **subtract**
> y −20.5…−14.5（深 6），z 7…13

**(5) USB-C 开口** — 方块 `9.5 × 4 × 3.4`，角点 `(−4.75, 16, 2.7)` → **subtract**

**(6) 侧壁透光孔** — 圆柱 φ3，方向 `[1,0,0]`，起点 `(12.5, −6, 4.2)`，深 8 → **subtract**

**(7) 四角圆角** — R4，选这 4 条竖直边：

| 边 | 取点（edge 上任意点） | 长度 |
|---|---|---|
| 右后 | (16.5, 20, 3) | 6 |
| 左后 | (−16.5, 20, 3) | 6 |
| 右前 | (16.5, −20, 9) | 18.75 |
| 左前 | (−16.5, −20, 9) | 18.75 |

> 用 `resolve_topology` 按 `{direction:[0,0,1], length, near_point}` 选边，
> 再用 `fillet_edges(body_index, edge_indices, radius=4)`。
> **R5 会失败**（后壁只有 6 高，圆角会越过相邻面），4 是上限。

## 8. 常见坑（踩过的）

1. **body 索引会变**：每次 `boolean_bodies` 之后重新 `inspect_work_part_geometry`，
   不要沿用旧索引（仓库示例就是这么写的）。
2. **圆角半径**：后壁只有 6mm 高 → R4 是上限；托台只有 3.9 厚 → R1.5。
3. **草图平面**：`plane:"YZ"` 时草图 2D 坐标 = (Y, Z)；`extrude_sketch` 的
   `start` 是沿 `direction` 的起点（NEMA 示例：start=−26、dir=+X、distance=4）。
4. **`create_block` 的 origin 是角点**，不是中心。
5. **光学头必须整体变换**，不要单独挪 P02–P08，否则 30° 关系会散。
6. **前唇高度**：托台上口与棱镜底面齐平，别自作主张加高（见第 3 节）。
7. **单位**：所有调用用 mm，表达式中带单位时注意 SolidCraft 是 `"33 mm"`，
   NX MCP 是纯数值 `33.0`，别混。
