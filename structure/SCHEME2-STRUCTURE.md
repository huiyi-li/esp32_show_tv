## 2. 高度预算：为什么是 41mm（不是 30–40）

棱镜的 45° 分光面是**做死在立方体里的**，而屏幕又必须紧贴并平行于棱镜底面
—— 所以**唯一的自由度就是"屏幕+棱镜一起后仰"**，后仰角 α 就等于人眼观察仰角。

```
整机高 ≈ HL_MIN  +  2·YH·sinα  +  HEAD_T·cosα
         ↑头最低点   ↑头进深的竖直投影   ↑头厚度的竖直投影
```

| 后仰角 α | 底座前高 | 整机高 | 说明 |
|---|---|---|---|
| 20° | 13.2 | **39.3 mm** | 唯一能压进 ≤40 的角度 |
| 25° | 15.4 | 40.6 mm | |
| **30°** | 17.6 | **41.7 mm** | ← 当前方案 |
| 35° | 19.7 | 42.4 mm | |
| 45° | 23.4 | 43.1 mm | 倾角再大几乎不再变高 |

改 `cad/build_prototype.py` 里的 `P["TILT"]` **一个参数**即可切换，脚本会自动重算全部尺寸。

> ⚠️ 25.4mm 棱镜在 30° 下，光是它自己的竖直投影就有 `25.4·(cos30°+sin30°) ≈ 34.7mm`。
> 所以"**30–40mm 总高**"和"**30° 仰角 + 像样的底座**"不可兼得：
> 要 ≤40mm 就把倾角降到 **20°**（得 39.3mm）；坚持 30° 就要接受 ~41.7mm。

## 3. 棱镜装配（核心）

### 3.1 棱镜的固定：只粘，不夹

v3 **取消了 v1/v2 的棱镜卡座、四角护角、顶部压框** —— 棱镜四个侧面 + 顶面全部外露。

- **粘接面**：遮光框顶面（外 26.0，内窗 23.4，**环宽 1.3mm**）。
- **粘接方式**：环形涂 **UV 光学胶**，胶层 **0.1mm**、外径 26.0（不外溢），
  UV 灯照 30–60s 固化。棱镜 25.4 < 26.0，所以整圈都有胶，承力均匀。
- **定位**：底座上做一圈 **阶梯托台**（外 32.0、四角 R2.5 / 下口 28.2 让开屏幕板 /
  上口 25.6 贴紧棱镜 / 顶面与**棱镜底面齐平**），正面 + 左右三面，背面开口便于装入。
  屏幕板、面板、遮光框全部藏在里面，棱镜直接从托台里伸出来。
- **⚠️ 为什么托台不高出棱镜底面**：人眼在 30° 仰角看时，前唇只要高出棱镜底面
  就会挡住画面下沿 —— 精确算下来只允许高出约 **1.0mm**。所以本设计的托台做成齐平；
  参考图那种 3–4mm 厚的包边，是因为那台机器的观看角更平（约 10–15°）。
  想要参考图的厚包边 → 把 `TILT` 降到 15°。
- **托台下方有一层托板**（z ≥ 4.5，y ≤ 2.0，顶面沿 30° 屋面），
  既支撑托台和光学头，又让主板从下面通过。
- **底座正面**开一个 **22×6mm 圆角盲槽**（深 6mm，R2.2），呼应参考图的简约造型。
- **不许用瞬干胶（502）**：会析出发雾、污染镀膜。只用 UV 胶或光学胶。
- **拆换**：加热到 60–80℃ 可软化 UV 胶取下棱镜（换 AR 膜或换尺寸）。

### 3.2 分光面方向（关键！）

**几何事实**：屏幕在下方朝上发光（传播方向 `+Z`），要让它反射到正面（`-Y`），
分光面必须是一条**包含 X 轴（左右水平方向）、在竖直 Y–Z 平面内倾斜 45°** 的平面。

用镜面反射公式 `r = d - 2(d·n)n` 验证（`d=(0,0,1)`，`n=(0,1,1)/√2`）：

```
r = (0,0,1) - 2·(1/√2)·(0,1,1)/√2 = (0,-1,0)   ✓ 正好射向正面
```

因此棱镜局部坐标下，**分光面方程为 `y + z = 0`**：

| 正确 ✅ | 错误 ❌ |
|---|---|
| 分光面从**前上棱**延伸到**后下棱** | 从前下棱延伸到后上棱 |
| `n = (0, 1, 1)/√2`（指向后上 / 前下） | `n = (0, 1, -1)/√2` |
| 光射向正面 `-Y` | 光射向背面 `+Y`，正面看不到图像 |

> ⚠️ 常见误区：写成"分光面**法线**在水平面内"。这是错的——光沿 `+Z` 传播时，
> 法线必须在**竖直的 Y–Z 平面**内倾斜 45°，法线才有 `±Z` 分量。

**装反的表现与排查**：正面看不到图像，或只能从背面看到 →
把棱镜绕竖直轴转 90°/180°/270° 各试一次即可确认（棱镜绕 Z 轴旋转会改变分光面朝向）。

**丝印/结构防呆**：卡槽一角做缺角（或在卡槽底画一根方向标记线），棱镜对应角用记号笔标记。

**v2 的整体后仰（与上面的关系）**：以上讨论的都在**光学头自身坐标系**里。
实际装配时整个光学头（屏幕 + 棱镜一起）绕 X 轴后仰 `TILT` 度，于是：

- 出射光的世界方向 = `R_x(−TILT)·(0,−1,0) = (0, −cos TILT, +sin TILT)`
  → 抬高 `TILT` 度，**正好对上人眼仰角**；
- 出射光**始终垂直于棱镜"正面"**，所以人眼是正对着看的，不会斜视把图像压扁；
- 屏幕法线随之变成 `(0, sin TILT, cos TILT)`：**屏幕前缘抬高、后缘降低**
  （想想把盒子往后一掀，底面就是前边翘起来）；
- 相对几何完全不变，所以分光面朝向的判断（上面那张表）依然适用。

> 结论：`TILT` 就是"人眼观察仰角"，`30°` 适合坐姿，`45°` 更接近低头看手机的姿势。

### 3.3 图像朝向（务必在固件里校准）

分光面是一面 45° 镜，且屏幕是**水平**的、而像面是**竖直**的，所以成像不是简单的旋转：

- 屏幕的 `+X` → 像的**水平向右**
- 屏幕的 `-Y`（朝前）→ 像的**竖直向上**

相机：屏幕点 `(x0, y0)` 成像在正面 `(水平, 竖直) = (x0, -y0)`。

因此 UI 的"上"必须朝向屏幕的**前边（`-Y`）**，"右"朝向 `+X`。
但这是**镜像**（手性反转，行列式为 −1），不是纯旋转——就像提词器一样，
反射后文字是反的，必须在固件里用 ST7789 的 **MADCTL（MY/MX/MV）** 组合校正。

**实操**：`esp_lcd_panel_mirror(panel, mx, my)` + `esp_lcd_panel_swap_xy(panel, mv)`
共 8 种组合，烧进去逐一试，选"文字正立且可读"的那一组，然后写回
`display.c` 的初始化里。当前 `display.c` 留的是 `swap_xy=false, mirror(false,false)`，
第一版硬件上板后按此方法确定。

### 3.4 遮光
- 屏幕板与棱镜之间必须加**黑色遮光框**：
  - 外框 25.0，内窗 23.4×23.4（= 显示区），厚 0.5，四角由卡座托边压住。
  - 材质：哑光黑 PETG / 黑色硅胶泡棉，避免内部反射。
- 外壳内壁喷**哑光黑**或贴黑色植绒，减少腔体反光。
- 屏幕板 FPC、背光线等**全部藏到显示窗外侧**，绝不进入显示窗。

### 3.5 光学优化（加分项）
- 棱镜底面与面板之间加**折射率匹配胶**或光学胶（如 UV 光学胶），可消除空气界面双影。
- 棱镜外表面镀 **AR 膜**，进一步降低鬼影。

## 4. 双板装配（v2）

v2 里两块板**不再平行**：屏幕板在倾斜 30° 的光学头里，主板水平躺在底座里。
所以两者之间用 **0.5mm 12P FPC（Z 折弯）**连接，而不是板对板对插。

### 4.1 连接方式
- **屏幕板**：27×27×0.8，底面对外引出 12P FPC（或板对板公座 + 短 FPC 转接）。
- **主板**：38×36×1.0，水平放在底座里，前端接 FPC 座。
- FPC 需要跨过 30° 夹角，长度留 **18–22mm**，在光学头下方做一次自然弯曲，
  **不要绷直受力**（温度变化会拉伤焊点）。
- 若坚持用板对板硬连接：只能在光学头里再加一小块"转接板"，
  先把 FPC 转成水平，再与主板对插 —— 成本更高，v2 不推荐。

### 4.2 光学头支撑
- 光学头**前下缘**落在底座前部的 **30° 托肩**上（与头底面共面，贴合 2.5mm）。
- 光学头**后下缘**最低点 Z=3.6，距底座底面很近，由主板顶面附近的
  小支撑台（或用主板边缘的矮垫片）限位。
- 4 个棱镜护角同时起"卡住棱镜 + 固定光学头"的作用，可用 M2 从侧面点锁。

### 4.3 装配顺序
1. 主板器件贴装完成 → 焊 FPC 座（前端）。
2. 屏幕板焊 FPC 座 + 背光电路；面板 FPC 折 180° 贴到屏幕板顶面。
3. 屏幕板装入光学头：遮光框 → 卡座 → 棱镜 → 四角护角 → 顶部压框。
4. 光学头整体（含已装好的屏幕板 FPC）以后仰 30° 放入底座托肩，
   把 FPC 前端插入主板 FPC 座并锁紧。
5. 棱镜按 3.2 的方向放入（**这一步先别点胶**，上电验证方向正确后再固化）。
6. 上外壳顶盖 / 前框，粘脚垫。
7. 上电验证：正面应能正对着看到悬浮图像；不对就把棱镜绕竖直轴转 90° 再试。

## 5. 传感器与开窗

### 5.1 BH1750 透光窗
- BH1750 在**主板右侧靠前**（约 `x = +15, y = −6`）。
- 外壳侧壁（`+X` 面）对应位置开 **φ3mm 磨砂透光孔**（或插 φ3mm 磨砂导光柱），
  模型里在 `x = +20 → +22, y = −5, z = 4` 处，内侧做倒角防直射。
- 窗口朝外、避开展示方向与握持区，避免被手 / 光学头遮挡。

### 5.2 MPU6050
- 在主板**中前部**（约 `x = −6, y = −6`），尽量靠底座中心，减少杠杆噪声。
- 远离 Buck 电感与 USB-C 大电流回路。
- 注意：IMU 在水平的主板上，而屏幕在倾斜的光学头里 ——
  做"翻转/摇一摇"交互时，**固件里要用 TILT 角把姿态换算到屏幕坐标系**。

### 5.3 USB-C 开口（v2 新增，后壁插电）
- USB-C 母座在主板**后缘**（`y = +19.5`），插口朝 `+Y`。
- 外壳**后壁**（`y = +20 → +22`）开缺口：**宽 9.5mm × 高 3.4mm，中心 z ≈ 4.0**。
- 开口向内做 0.5mm 喇叭倒角，插拔时不顶主板；开口下沿留 2mm 让线能自然下垂。
- 主板后缘离后壁内表面只有 0.5mm，**插拔力直接由外壳承担**，不要压在 PCB 上。

### 5.4 触摸
- 外壳内侧贴 8×8mm 铜箔，走线引到主板 GPIO4 区域。
- 铜箔位置在**顶部/侧面非显示区**，下方不能有大面积金属。

## 6. 天线与外壳材质（重要）

- 主板 PCB 天线放在主板**后侧边、远离棱镜投影**，装配后正对外壳**非金属侧壁**。
- 天线净空 15×8mm 区域对应的外壳壁厚尽量薄（≤1.5mm），**不得贴金属箔、不得喷导电漆**。
- 若改成**铝合金外壳**：PCB 天线会被严重失谐 → 必须换 **U.FL + 外置 FPC 天线**，贴在外壳内侧非金属窗口。

| 工艺 | 适用 | 要点 |
