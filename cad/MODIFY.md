# 怎么改这个设计（FreeCAD 操作指南）

模型文件：`cad/out/PrismTV_Assembly.FCStd`（用 FreeCAD 1.1 打开）

它的结构和机械设计一致：**总装 → 子装配 → 零件 → 特征**。所有零件都是独立对象，
可以单独改尺寸、单独导出、单独替换。

---

## 1. 树结构

```
PrismTV_总装                  (App::Part)
├── ASM-01 外壳组件            (App::Part)
│   └── P01 外壳底座           (Part::Fillet)
│       └── CUT_透光孔          (Part::Cut)
│           ├── CUT_USBC
│           ├── ...
│           └── EX_外壳毛坯     (Part::Extrusion)
│               └── SK 外壳侧剖面 (Sketcher::SketchObject)  ← 轮廓在这里
├── ASM-02 光学头组件           (App::Part, Placement = 后仰 30°)
│   ├── P02 棱镜托台            (Part::Cut 链)
│   ├── P03 屏幕板
│   ├── P04 显示面板
│   ├── P05 遮光框
│   ├── P06 光学胶
│   ├── P07 分光棱镜
│   └── P08 分光膜
├── ASM-03 主板组件             (App::Part)
│   ├── P09 主板
│   └── C01 ~ C11 元件
├── 参数                        (Spreadsheet，带别名)
└── BOM                         (Spreadsheet)
```

## 2. 改参数的三种方式

### ① 改电子表格（最快）
双击 **参数** → 改 B 列数值。已绑定表达式的尺寸会**自动更新**：

| 别名 | 绑定到 |
|---|---|
| `BW` / `WALL` | 外壳底座宽度 / 壁厚 |
| `TILT` | 光学头后仰角（见第 4 节） |
| `PRISM` | 棱镜三个方向的尺寸 |
| `YH` / `PCB_T` | 屏幕板尺寸 |
| `MAIN_W` / `MAIN_D` / `MAIN_T` | 主板尺寸 |

没绑定的尺寸（如盲槽、USB-C 口）请在对应 `BOX_*` 对象里直接改。

### ② 改零件外形
- **外壳轮廓**：双击 `SK 外壳侧剖面`，拖动顶点或改约束尺寸。
  这是"前高 18.75 → 后平台 6.0"的那条折线，**拉伸会自动跟着变**。
- **盲槽 / USB-C 口 / 透光孔**：点 `BOX_前槽` / `BOX_USBC` / `CYL_透光孔`，
  在属性栏改 `Length/Width/Height` 或 `Placement`。
- **四角圆角**：点 `P01 外壳底座`（Part::Fillet），改 `Edges` 里的半径。

### ③ 改装配位置 / 角度
- **后仰角**：选中 `ASM-02 光学头组件` → 属性 `Placement` → `Rotation.Angle`
  （当前 −30°）。改一个数，整个光学头（屏幕+棱镜+托台）一起转。
- **整体高度**：同样改 `ASM-02` 的 `Placement.Base.z`（当前 10.6）。
- **单个零件挪位置**：直接改该零件自己的 `Placement`。

## 3. 改完之后要重新导出的东西

| 产物 | 方法 |
|---|---|
| 3D 打印 STL | 选中零件 → 文件 → 导出 → STL，或跑 `python3 cad/build_assembly.py --no-render` 重生成 |
| 整机 STEP | 选中 `PrismTV_总装` → 导出 STEP |
| 工程图 | `python3 cad/make_drawings.py`（读 FCStd 生成 PNG） |
| 效果图 | `DISPLAY=:1 freecad cad/build_assembly.py`（会重渲染） |

## 4. ⚠️ 后仰角不是随便改的

`TILT` 是**光学量**，不是造型量：

```
出射光方向 = (0, −cos TILT, +sin TILT)
```

- `TILT` = 人眼观察仰角。坐姿看桌面设备，30° 合适；45° 更接近低头看手机。
- 改大 → 画面更"正对眼睛"，但整机更高（25.4 棱镜的竖直投影 ≈ 25.4·(cos+sin)）。
- 改小 → 更矮，但桌面观看时画面被竖向压扁：30° 压 13%，15° 压 26%。
- **前唇高度限制**：托台前唇每高出棱镜底面 1mm，30° 视线下会挡掉约 1.7mm 画面。
  有效显示区只留 1mm 边距 → **前唇最多只能高出约 1.0mm**。
  想要参考图那种厚包边，必须把 `TILT` 降到 15° 左右。

## 5. 装配顺序（装配图里的说明）

1. `P07 分光棱镜` 用 `P06 光学胶`（0.1mm 环）粘到 `P05 遮光框` 上，UV 固化。
2. `P03 屏幕板` + `P04 显示面板` 装进 `P02 棱镜托台` 的内台阶。
3. 遮光框组件压到屏幕板上，一起从**后面**推进 `P02` 托台。
4. `P02 托台` 装到 `P01 外壳底座` 的斜面上（可胶接或卡扣）。
5. `P09 主板` + 元件装入腔体，USB-C 对准后壁开口。
6. 屏幕板 12P FPC 接到主板，上电验证成像方向后再点胶固定棱镜。

## 6. 已知的"不参数化"部分

为了不把手工程图做成一堆失败的特征，以下几处是**独立实体/布尔链**，
需要改尺寸时直接改对应对象，而不是改一个总参数：

- 托台（P02）的阶梯内口尺寸写在 `BOX_托台上口/下口` 里。
- 前部盲槽是方块（没有圆角），要圆角请对 `P01` 再加一个 Fillet。
- 主板元件是代表性建模，位置直接对应 `C01~C11` 的 Placement。
