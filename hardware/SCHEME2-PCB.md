# 方案二 硬件设计说明（主板 + 屏幕板）

> 对应 `DESIGN.md` 方案二。主控 ESP32-PICO-D4，双板结构，**25.4mm** 分光棱镜。
> 本文件给出：板卡规格 → 框图 → 网表 → 叠层 → BOM → Layout 规则 → 测试点。

---

## 1. 板卡规格总览

| 项目 | 主板 Main Board | 屏幕板 Display Board |
|---|---|---|
| 尺寸 | 28 × 28 mm | 28 × 28 mm（在倾斜光学头里） |
| 层数 / 厚度 | 4 层 / 1.0 mm | 2 层 / 0.8 mm |
| 铜厚 | 1 oz | 1 oz |
| 阻焊/丝印 | 哑光黑 / 白 | 哑光黑 / 白 |
| 表面处理 | 沉金 ENIG | 沉金 ENIG |
| 装配面 | 顶面=连接器+小件；底面=主控/电源/USB/传感器 | 顶面=面板 FPC+背光；底面=板对板连接器 |
| 安装孔 | 4 × M2 (φ2.2) | 4 × M2 (φ2.2) |
| Mark 点 | 3 个 (φ1.0 裸铜 + 阻焊开窗) | 3 个 |

**分板原则**：棱镜正下方只有 25.4mm 窗口 → 屏幕板越薄越简单；MCU/电源/USB/传感器堆叠密度大 → 全放主板。

## 3. 主板网表（按功能块）

### 3.1 U1 — ESP32-PICO-D4

| 模块引脚 | 网络名 | 外围 |
|---|---|---|
| VDD3P3 (×多个) | +3V3 | 每脚 0.1µF，模块旁 10µF + 22µF |
| VDD3P3_RTC | +3V3 | 0.1µF + 10µF |
| VDD_SDIO | +3V3 | 0.1µF（内部 Flash 供电） |
| VDDA / VDDA3P3 | +3V3 | 可选磁珠 + 0.1µF/10µF π 滤波 |
| EN | EN | 10kΩ↑3V3 + 0.1µF 到 GND + 复位按键 SW1 |
| GPIO0 | IO0 | 10kΩ↑3V3 + BOOT 按键 SW2 |
| GPIO2 | LED_STATUS | 经 1kΩ 接 D1（内部指示，可空） |
| GPIO5 | LCD_CS | 到 J2 |
| GPIO18 | LCD_SCLK | 到 J2（可选串 33Ω） |
| GPIO23 | LCD_MOSI | 到 J2（可选串 33Ω） |
| GPIO27 | LCD_DC | 到 J2 |
| GPIO33 | LCD_RST | 到 J2 |
| GPIO32 | LCD_BL | 到 J2（LEDC PWM 20kHz） |
| GPIO21 | I2C_SDA | 4.7kΩ↑3V3，接 U4/U5 |
| GPIO22 | I2C_SCL | 4.7kΩ↑3V3，接 U4/U5 |
| GPIO34 | IMU_INT | U4 INT（仅输入） |
| GPIO4 | TOUCH1 | 触摸铜箔（串联 1MΩ 可选），远离 SPI |
| GPIO35 | VBUS_DET | +5V 经 100k/100k 分压 |
| GPIO25 | RGB_DIN | WS2812 数据（可选，串 330Ω） |
| GPIO1 / GPIO3 | UART0_TX / RX | 到 U2 |
| **GPIO12** | **NC** | **悬空或 10kΩ↓GND，禁止拉高** |
| GPIO6–11 / 16 / 17 | — | 内部 Flash，PCB 上留空焊盘但不接任何网络 |
| 其余 GPIO | 预留 | 引到测试点排 |

> LGA-48 焊盘**必须直接引用 Espressif 官方 Datasheet 第 9 章 Packaging 的 land pattern**，不要自行缩放或改 pitch。

### 3.2 U2 — USB-UART 桥 + 自动下载

| 器件 | 接法 |
|---|---|
| U2 CH340C（推荐，内置晶振）| VCC=+3V3，TXD→GPIO3，RXD←GPIO1，D+/D-←J1 |
| 备选 | CV3000P / CP2102N / CH343P（注意各自晶振与供电差异） |
| Q1/Q2 自动下载 | 经典 NodeMCU 交叉电路：DTR/RTS 经 10kΩ 分别驱动 Q1/Q2 基极，集电极分别接 EN 与 IO0，发射极 GND；EN、IO0 各自 10kΩ 上拉到 +3V3 |
| 按键 | SW1 = RESET(EN→GND)，SW2 = BOOT(IO0→GND) |

### 3.3 U3 — 电源

| 网络 | 器件 |
|---|---|
| VBUS | J1 USB-C，CC1/CC2 各 5.1kΩ↓GND（Sink），VBUS 串 F1 0.5A 保险 → +5V |
| ESD | USBLC6-2SC6 保护 D+/D-/VBUS |
| +5V | 屏幕板背光供电；VBUS_DET 分压采样 |
| +3V3 | Buck：TPS62162 / MP2315 / SY8089（≥600mA，留 WiFi 尖峰裕量）<br>备选 LDO：RT9013-33 / AP2112K-3.3（600mA） |
| 输出滤波 | 22µF + 10µF + 0.1µF；反馈电阻按 datasheet |
| 指示 | D2 电源 LED（+3V3 经 1kΩ） |

> ESP32 在 WiFi TX 瞬时可达 ~500mA，Buck 额定电流建议 ≥1A，输出电容 ≥22µF。

### 3.4 U4 — MPU6050

| 引脚 | 网络 |
|---|---|
| VDD | +3V3，0.1µF |
| VLOGIC | +3V3，0.1µF（或 10nF，按手册） |
| GND | GND |
| AD0 | GND → 地址 **0x68** |
| SDA / SCL | I2C_SDA / I2C_SCL |
| INT | IMU_INT (GPIO34) |
| CPOUT | 2.2nF 到 GND（按手册） |
| REGOUT | 0.1µF 到 GND |
| 封装 | QFN-24 4×4×0.9mm |

### 3.5 U5 — BH1750FVI（放主板，靠外壳侧面透光窗）

| 引脚 | 网络 |
|---|---|
| VCC | +3V3，1µF + 0.1µF |
| GND | GND |
| ADDR | GND → 地址 **0x23** |
| DVI | GND（或经 0.1µF 到 +3V3，按手册） |
| SDA / SCL | I2C_SDA / I2C_SCL |

> ⚠️ **位置修正**：BH1750 **不放屏幕板**。屏幕板正上方被 25.4mm 棱镜完全遮挡，采不到环境光。改放主板靠侧壁位置，外壳对应开**磨砂透光窗或导光柱**。

### 3.6 触摸焊盘

- 屏幕板/主板不接触的正对面上、外壳内侧贴**铜箔**或主板边缘画**裸露铜焊盘**，1MΩ 串阻后接 GPIO4。
- 铜箔面积建议 ≥ 8×8mm，下面**不能有地平面**（否则电容被吃掉），地平面挖空 ≥1mm。
- 走线远离 SPI、Buck 电感、WS2812。

### 3.7 板对板连接器 J2（14P，0.4/0.5mm）

| Pin | 信号 | 方向 |
|---|---|---|
| 1 | +3V3 | PWR |
| 2 | +5V | PWR（背光） |
| 3 | GND | GND |
| 4 | GND | GND |
| 5 | LCD_SCLK | 主→屏 |
| 6 | LCD_MOSI | 主→屏 |
| 7 | LCD_CS | 主→屏 |
| 8 | LCD_DC | 主→屏 |
| 9 | LCD_RST | 主→屏 |
| 10 | LCD_BL | 主→屏（PWM） |
| 11 | I2C_SDA | 预留（未来屏上触控） |
| 12 | I2C_SCL | 预留 |

推荐：Hirose DF40C-14DP-0.4V / Molex SlimStack，配对高度 2.0–3.0mm。

## 4. 屏幕板设计

### 4.1 框图

```
   J3 (14P 板对板, 背面) ──► 3V3 / 5V / GND / SPI / BL
                                    │
                                    ▼
   ┌──────────────┐   FPC1 (8P 0.5mm)  ┌──────────────┐
   │  1.3" 240×240│◄───────────────────►│  ST7789S 面板│ (COG, 驱动+电荷泵电容在 FPC 上)
   │  屏幕板 25×25 │                     └──────────────┘
   │              │──► Q1 背光开关 ──► 限流 R1(或恒流 IC)
   └──────────────┘
```

### 4.2 网表

| 器件 | 接法 |
|---|---|
| FPC1 | 1.3" 240×240 8P FPC：`1 GND / 2 VCC(+3V3) / 3 SCL / 4 SDA / 5 RES / 6 DC / 7 CS / 8 BLK` |
| FPC1-3/4/5/6/7 | 直连 J3 的 SCLK/MOSI/RST/DC/CS |
| FPC1-2 | +3V3，C1=1µF + C2=0.1µF 就近 |
| 背光 A 方案（面板有 LEDA/LEDK）| **N-MOSFET Q1 低边开关** + 限流电阻或恒流 IC，栅极经 100Ω 接 LCD_BL，栅极 100kΩ↓GND |
| 背光 B 方案（8P 单 BLK=阳极）| **P-MOSFET 高边开关**（DMP3098L 等）+ 限流电阻，用 NPN/NMOS 做电平翻转驱动 |
| 限流 R1 | R = (Vsrc − Vf) / If。Vf≈2.8–3.2V，If≈15–20mA；用 +5V 供电裕量更足 |
| C1–C4 | +3V3 去耦 1µF + 0.1µF；+5V 侧 10µF + 0.1µF |
| R2/R3 | SPI 源端串阻 22–33Ω（如振铃明显再加） |
| D1 | 可选 ESD（FPC 走线暴露区） |

> 优先选**带独立 LEDA/LEDK 的 12P 面板**，可做真正的低边恒流调光；只有 8P 时按 B 方案做高边 PWM。

## 7. Layout 规则

### 7.1 射频 / 天线
- PCB 天线净空 **15 × 8 mm**：L1 不铺铜、不走线、不放过孔；L2 对应区挖空。
- 净空区距棱镜、屏幕板、电池、金属结构件 ≥ 5mm。
- 天线放在**主板远离 USB 与 DC/DC 电感**的板边，且装配后朝**外壳非金属侧壁**。
- 40MHz 晶振在模块内部，无外部晶振走线。
- 若用金属外壳 → 必须改 **U.FL + 外置 FPC 天线**。

### 7.2 电源
- Buck 输入回路（Cin → 电感 → 输出电容）**面积最小化**，环路 < 10mm²，远离天线与 I2C。
- 电感选屏蔽型，远离 IMU 与触摸走线。
- ESP32 每个电源脚 **0.1µF 就近到过孔到 L2 GND**，模块旁 22µF + 10µF。
- +3V3 与 +5V 在 L3 分域，各自单点回地。

### 7.3 SPI（跨板对板）
- 总长 < 50mm；走线尽量等长，与 I2C 保持 ≥3W 间距。
- 参考地连续，跨连接器时每 2–3 根信号配 1 根 GND。
- 若 40MHz 出现花屏/振铃：SCLK/MOSI 串 22–33Ω 源端电阻，或降到 26MHz。
- 屏幕板 SPI 走线两侧包地并打回流过孔。

### 7.4 I2C
- 4.7kΩ 上拉到 +3V3，总线电容 < 400pF；走线短、平行靠近。
- 远离 Buck 电感 ≥ 5mm，避免开关噪声耦合。

### 7.5 USB
- D+/D- 90Ω 差分，等长（±0.15mm），包地并打过孔。
- ESD 器件紧贴连接器。

### 7.6 触摸
- 触摸焊盘下方**挖空地平面** ≥1mm，焊盘与周围走线间距 ≥1mm。
- 触摸焊盘附近禁止大电流/高频走线。

### 7.7 背光
- 背光电流回路（+5V → 面板 → 开关 → GND）加宽到 ≥0.5mm。
- PWM 频率 ≥10kHz，避免与 I2C/SPI 同频干扰。

### 7.8 安规 / DFM
- 最小线宽/间距 0.15/0.15mm；过孔 0.2/0.4mm；板边距 ≥0.3mm。
- 阻焊开窗避开 SPI 走线（防短路）。
- 板对板连接器周围留 ≥1mm 无器件区，方便对插。

## 9. 打样与装配注意

1. **先打主板 + 屏幕板各 5 片**，验证 SPI 与背光，再改结构。
2. LGA-48 焊盘按官方 land pattern，钢网开孔按 1:1，回流曲线按 Espressif 建议（峰值 235–245℃）。
3. USB-C 用**能过数据的版本**（有些只供电），否则无法下载/调试。
4. 板对板连接器先不焊，用飞线调通 SPI 参数，确认后再焊。
5. 屏幕板 SPI 走线尽量短，越短越容易跑到 40MHz。
6. 丝印标注：`FRONT↑`（棱镜前/上方向）、`J2 PIN1`、板卡版本号。
